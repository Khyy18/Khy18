# Мобильное приложение бухгалтера детского сада

Минималистичное Android-приложение для автоматизации бухгалтерского учёта в дошкольном учреждении.

## Функции

- Расчёт заработной платы (оклад, надбавки, НДФЛ, взносы)
- Расчёт отпускных
- Расчёт больничного листа
- Табель учёта рабочего времени
- Учёт детей и родительской платы
- Журнал доходов/расходов
- Справочник КБК
- Напоминания о дедлайнах
- Формирование платёжных поручений
- AI-ассистент (интеграция с Groq LLM)

## Технологии

- **Flutter 3.24** (Dart 3.5)
- **Riverpod** - управление состоянием
- **Hive** - оффлайн кэширование данных
- **GoRouter** - навигация
- **Google Fonts** (Space Grotesk, Manrope)
- **flutter_animate** - микро-анимации
- **fl_chart** - графики

## Дизайн

Минималистичный стиль с уникальной визуальной идентичностью:
- Плоские карточки без теней, с тонкой рамкой и скруглением 20px
- Крупная типографика (Space Grotesk для заголовков, Manrope для текста)
- Один акцентный цвет (индиго-фиолетовый #6366F1)
- Асимметричные раскладки
- Gradient-кнопки для главных действий
- Плавные входные анимации

## Настройка

### Требования

- Flutter SDK 3.24+
- Android SDK (API 21+)
- Java 17

### Установка зависимостей

```bash
flutter pub get
```

### Конфигурация API

Отредактируйте файл `lib/config.dart`:

```dart
static const String apiBaseUrl = 'http://ваш-сервер:8000/api/v1';
```

Для запуска на эмуляторе используется `http://10.0.2.2:8000/api/v1` (обращение к localhost хост-машины).

### Запуск в режиме отладки

```bash
flutter run
```

### Сборка APK

Debug APK:
```bash
flutter build apk --debug
```

Release APK:
```bash
flutter build apk --release
```

Результат: `build/app/outputs/flutter-apk/app-debug.apk`

## Структура проекта

```
lib/
  config.dart           - конфигурация приложения
  main.dart             - точка входа, роутинг
  theme/
    app_theme.dart      - Material 3 тема
    app_colors.dart     - палитра цветов
  models/               - модели данных
  services/
    api_service.dart    - HTTP-клиент к backend
    local_storage.dart  - Hive оффлайн-кэш
  providers/            - Riverpod провайдеры
  screens/              - 12 экранов приложения
  widgets/              - переиспользуемые виджеты
  l10n/                 - локализация
```
