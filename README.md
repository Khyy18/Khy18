# Khy18 - Multi-Project Repository

This repository contains 4 independent projects:

## Projects

### [01 - Zenith Crypto Trading](./01_zenith_crypto_trading/)
Multi-exchange crypto trading bot with AI-powered decision gates, multi-timeframe Donchian strategy, kill-switches, and Telegram terminal. Supports Bybit V5 and OKX.

### [02 - Sports Betting Arbitrage](./02_sports_betting_arbitrage/)
Sports betting arbitrage system for detecting and executing profitable cross-bookmaker opportunities.

### [03 - AI Office](./03_ai_office/)
Multi-agent AI system for office automation with specialized agents and API interface.

### [04 - AI Text Agency](./04_ai_text_agency/)
AI-powered freelance automation and text services platform: CRM, payments, content generation, support chatbot, lead scoring, fraud detection, and more.

## Structure

Each project is self-contained with its own:
- `main.py` - entry point
- `requirements.txt` - dependencies
- `README.md` - documentation
- `.env.example` - environment variables template
