# Бот-бухгалтер детского сада

Telegram-бот для главного бухгалтера детского сада. Автоматизирует расчеты заработной платы, отпускных, больничных, ведение табеля, учет родительской платы и формирование платежных поручений.

## Возможности

- Расчет заработной платы с учетом НДФЛ и страховых взносов
- Расчет отпускных
- Расчет больничных листов
- Ведение табеля учета рабочего времени
- Учет родительской платы
- Настройка напоминаний о сроках отчетности
- Справочник КБК/КВР
- Формирование платежных поручений
- Журнал доходов и расходов

## Установка

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Укажите токен бота в файле `config.py`:

```python
BOT_TOKEN = "ваш_токен_от_BotFather"
```

3. Запустите бота:

```bash
python -m kindergarten_accountant_bot.main
```
