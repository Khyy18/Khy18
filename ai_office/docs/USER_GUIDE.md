# AI Office - Руководство пользователя

## Что такое AI Office?

AI Office - это ваша "карманная компания": команда из 8 AI-агентов, которая работает как полноценный офис прямо в Telegram. Каждый агент специализируется на своей области и может взаимодействовать с коллегами, делегировать задачи, составлять планы и отчитываться о выполнении.

Вы управляете командой через Telegram Mini App - современный веб-интерфейс внутри мессенджера с Kanban-доской, дашбордом метрик и чатом с каждым агентом.

---

## Быстрый старт

### 1. Установка

```bash
git clone <repository-url>
cp .env.example .env
# Заполните .env (минимум: OPENAI_API_KEY и TELEGRAM_BOT_TOKEN)
```

### 2. Запуск

```bash
docker compose -f ai_office/deploy/docker-compose.yml up -d
```

### 3. Открытие

Откройте вашего Telegram-бота и нажмите кнопку "Mini App". Вы увидите дашборд с метриками и список агентов.

## Интерфейс Mini App

### Вкладки

| Вкладка | Описание |
|---------|----------|
| Dashboard | Дашборд с метриками: задачи за день, расходы, активные агенты, график активности |
| Tasks | Kanban-доска задач (open, in_progress, done) с фильтрацией и drag-and-drop |
| Agents | Список агентов с аватарами, статусами и возможностью начать чат |
| Activity | Лог активности команды в реальном времени |
| Plans | Планы работ с шагами и прогрессом выполнения |

### Шаблоны задач

Система предоставляет готовые шаблоны для быстрого создания типовых задач:

- **Code Review** - ревью кода (исполнитель: Sam)
- **Bug Fix** - исправление бага (исполнитель: Sam)
- **Design Review** - ревью дизайна (исполнитель: Max)
- **Write Tests** - написание тестов (исполнитель: Leo)
- **Deploy to Production** - деплой (исполнитель: Nova)
- **SEO Audit** - SEO-аудит (исполнитель: Iris)
- **Budget Report** - финансовый отчет (исполнитель: Oscar)
- **Create User Story** - user story (исполнитель: Alice)

### Обратная связь

После каждого ответа агента можно оставить оценку (1-5 звезд) или отметить ответ как полезный/бесполезный. Статистика доступна на эндпоинте `/api/feedback/stats`.

## Проактивные задачи

Агенты работают не только по запросу. Система автоматически выполняет:

| Задача | Расписание | Описание |
|--------|-----------|----------|
| Ежедневный стендап | Каждый день в `STANDUP_HOUR` (UTC) | Обзор задач на день, блокеров и приоритетов |
| Недельный отчет | Раз в неделю (`WEEKLY_REPORT_DAY`) | Сводка по метрикам, завершенным задачам, расходам |
| Проверка просроченных | Каждые `OVERDUE_CHECK_INTERVAL_HOURS` ч | Алерт о задачах с истекшим дедлайном |
| Health check | Каждые `HEALTH_CHECK_INTERVAL_HOURS` ч | Проверка здоровья сервисов и инфраструктуры |

## FAQ

### 1. Как добавить нового агента?

Есть два способа: через код (создать файл в `agents/`) или через плагин (директория в `plugins/` с `manifest.yaml`). Подробности в [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md).

### 2. Как изменить модель LLM?

Укажите нужную модель в переменной окружения `OPENAI_MODEL`. Поддерживаются провайдеры OpenAI, Anthropic и Groq с автоматическим fallback.

### 3. Можно ли ограничить расходы?

Да. Установите `DAILY_BUDGET_USD` - система заблокирует запросы при превышении лимита. Также работает rate limiter: `GLOBAL_RPM_LIMIT` и `AGENT_RPM_LIMIT`.

### 4. Как работает аутентификация?

Через Telegram initData (HMAC-SHA256). Mini App автоматически передает данные пользователя, сервер проверяет подпись через секрет бота.

### 5. Можно ли использовать без Telegram?

Да, в dev-режиме (`SKIP_TELEGRAM_AUTH=true`) API доступен без аутентификации. Удобно для разработки и тестирования.

### 6. Как агенты взаимодействуют между собой?

Через механизм делегирования. Любой агент может вызвать `delegate_to_agent` для передачи подзадачи другому специалисту. Вся цепочка фиксируется в delegation trace.

### 7. Что такое плагины?

Плагины позволяют расширять систему без изменения основного кода. Положите директорию с `manifest.yaml` и `tools.py` в папку `plugins/` - система автоматически загрузит нового агента с инструментами.
