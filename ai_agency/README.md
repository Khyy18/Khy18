# AI-Агентство - Telegram-бот

Автоматизированное AI-агентство для обработки текстовых заказов через Telegram.

## Описание

Система состоит из двух Telegram-ботов:
- **Клиентский бот** - приём заказов на текстовые услуги
- **Админский бот** - управление, статистика, пополнение балансов

## Услуги

| Услуга | Описание | Цена |
|--------|----------|------|
| Копирайтинг | Посты, статьи, описания товаров | 150 ₽ |
| Рерайт | Уникализация текста | 100 ₽ |
| SEO-оптимизация | Оптимизация для поисковиков | 200 ₽ |
| Перевод RU-EN | Профессиональный перевод | 180 ₽ |
| Саммари | Краткое изложение | 120 ₽ |
| Деловые документы | КП, вакансии, резюме | 250 ₽ |

## Установка

```bash
# Клонируйте репозиторий и перейдите в директорию
cd ai_agency

# Установите зависимости
pip install -r requirements.txt
```

## Переменные окружения

Создайте файл `.env` или установите переменные:

```bash
# Токен клиентского бота (получить у @BotFather)
TELEGRAM_BOT_TOKEN=your_bot_token

# Токен админского бота (отдельный бот у @BotFather)
TELEGRAM_ADMIN_BOT_TOKEN=your_admin_bot_token

# Ваш Telegram ID (получить у @userinfobot)
ADMIN_TELEGRAM_ID=123456789

# Ключ OpenAI API
OPENAI_API_KEY=sk-your-key

# Модель (по умолчанию gpt-4o-mini)
DEFAULT_MODEL=gpt-4o-mini

# Путь к БД (по умолчанию agency.db)
DATABASE_PATH=agency.db
```

## Запуск

### Клиентский бот

```bash
python bot.py
```

### Админский бот

```bash
python admin_bot.py
```

### Оба бота одновременно

Запустите в двух терминалах или используйте скрипт:

```bash
python bot.py &
python admin_bot.py &
```


## Как это работает

1. Клиент запускает бота командой `/start`
2. Выбирает услугу из списка
3. Отправляет текст для обработки
4. Подтверждает заказ
5. Система проверяет баланс и списывает средства
6. Текст обрабатывается через OpenAI API (gpt-4o-mini)
7. Результат проходит проверку качества
8. Клиент получает готовый текст

## Админские функции

- Просмотр статистики (заказы и выручка за день/неделю/месяц)
- Список последних заказов
- Список клиентов с балансами
- Пополнение баланса клиентам

## Технологии

- Python 3.11+
- python-telegram-bot 20+
- OpenAI API (gpt-4o-mini)
- Pydantic v2
- aiosqlite (асинхронный SQLite)
