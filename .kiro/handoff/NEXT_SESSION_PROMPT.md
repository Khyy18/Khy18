### FEAT-A · Sparkline свечей в карточке позиции

- В карточке `📈 ПОЗИЦИИ` для каждой пары добавить мини-чарт из последних **30 close-цен** через символы `▁▂▃▄▅▆▇█`.
- Источник данных: OKX REST `GET /api/v5/market/candles?instId={symbol}&bar=15m&limit=30`.
- Кэш: 60 секунд на пару, in-memory (не БД).
- Хелпер `_sparkline_8(values: list[float]) -> str` (минимум 8 символов, можно длиннее).
- Нормализация: `(v - min) / (max - min) * 7` → индекс в `▁▂▃▄▅▆▇█`. Если `max == min` — все символы `▄`.
- Вызов асинхронный через `aiohttp` (он уже используется), таймаут 5с.
- При ошибке загрузки — sparkline не показывается, остальная карточка работает как раньше.

### FEAT-B · Прогресс-бары там, где даёт смысл

Расширить применение существующего `_progress_bar_10(used, limit)` на:

- **Винрейт 24ч** в карточке `📊 СТАТУС` — бар к 100%.
- **Дневной лимит сделок** — бар `сделок_24ч / MAX_TRADES_PER_DAY`.
- **Использование риска** — бар суммарного открытого риска / `MAX_PORTFOLIO_RISK`.
- **Прогресс серии LOSS** для пар на грани авто-блока — бар `текущая_серия / AUTO_BLOCK_LOSS_STREAK` (например 2/3 = `▰▰▰▰▰▰▰▱▱▱`), показывать в `🚫 ЗАПРЕТЫ` рядом с парой как warning.

### FEAT-C · Подсказки-объяснения по тапу

- Кнопка `❓` рядом с непонятными терминами в карточках (Sharpe, PF, fail-CLOSED, AI-Gate, Max DD, gate.verdict, shadow/active).
- Callback `zc:explain:<key>` → отправляет короткое объяснение (1-3 предложения на русском) через `_card`.
- Словарь `EXPLAIN: dict[str, str]` в `telegram_bot.py` с ~12-15 ключами.
- После объяснения — кнопка `◀ Назад`, возвращает к экрану откуда вызвали (через `chat_id` → последнее `message_id` или просто на главное меню если не сохранили).
